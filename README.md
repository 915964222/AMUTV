# 📺 影视TV Web(类 TVBox 影视应用)

一个纯网页版的"影视TV",界面与交互对标电视盒子的 TVBox/影视仓:

- 🖥️ **电视大屏 UI**:深色主题、焦点放大发光,适配遥控器操作
- 🎮 **遥控器式导航**:方向键在卡片间移动焦点,Enter 确认,Esc/Backspace 返回(也支持鼠标)
- 🗄️ **多仓 / 接口订阅**:支持 URL 订阅或粘贴 TVBox 配置 JSON(单仓 `sites` / 多仓 `urls`·`storeHouse`),
  自动解析苹果CMS影视站并加入数据源;`clan://` 相对地址按仓库基址解析;爬虫类源自动跳过;支持刷新/退订
- 🔎 **多源全网搜索**:并发搜索全部源(并发数可调),按源分组展示结果与响应耗时,失败源单独提示;
  支持**拼音/拼音首字母**(如 `dxt` → 大雄兔);结果支持**速度优先 / 清晰度优先**排序(蓝光/1080/720/抢先 自动识别)
- 🔀 **手动/自动换源**:播放页「换源」面板列出其他源的同名影片(含画质备注与耗时);播放失败或**卡顿超15秒**
  自动尝试其他源(可在设置开关,默认开,最多3次)
- ☁️ **网盘原画直连**:双协议挂载 —— **Alist**(推荐:聚合阿里云盘/夸克/百度网盘/115,填 Token 即可,302 直连
  网盘原始直链不经转码)与 **WebDAV**(坚果云等);目录浏览、面包屑导航;内置演示盘
  `http://localhost:9978/dav/`(WebDAV)与 Alist 模式挂 `http://localhost:9978`
- 🕵️ **底层智能嗅探**:播放页「🔍 嗅探」(快捷键 V)可对网页型播放地址开启嗅探:本地代理以 `/sniff/` 转换模式
  加载网页(剥离 X-Frame-Options/CSP、同源化),注入 fetch/XHR/setAttribute/MutationObserver 四路钩子,
  自动捕获动态加载、加密混淆的 m3u8/mp4 真实直链,点击即直连播放
- ▶️ **播放器**:HLS(m3u8,多码率自适应)/ MP4 直连,网页型链接 iframe 兜底;快进快退、倍速、全屏、音量、选集、上下集
- ⏯️ **断点续播**:退出后自动记忆位置,"继续观看"一栏直接续播
- ⭐ **收藏 / 历史**:本地保存,支持管理
- 🌐 **本地代理**:`/proxy/<url>`(及缓存隔离别名 `/proxy2/`)转发接口、图片与视频流,解决跨域、防盗链与
  HTTP 混合内容;HTTP/2 优先回退 HTTP/1.1、干净请求头、跟随重定向、支持 Range 拖动、可选 Basic 认证(网盘)

## 快速开始

**方式〇:安卓 App** 📱

安装根目录的 `yingshi-tv.apk`(2.9MB)—— 网页资源已全部内嵌,**独立运行不依赖电脑**,
数据源直连(WebView 通用访问免跨域),HLS/MP4/选集/换源/收藏/历史/网盘(Alist+WebDAV)全部可用。
嗅探与"源测试"依赖本地代理,App 内不可用。重新打包:`build-apk.bat`(工具链在 `%LOCALAPPDATA%\android-sdk-tmp`)。

**方式一:桌面 App**

双击 `启动影视TV.bat` —— 首次自动安装运行时,之后直接弹出电视窗口(F11 全屏体验最佳)。
Electron 壳会自动拉起内嵌服务器,无需先启动 server。

**方式二:浏览器 + PWA**

```bash
cd tvbox-web
node server.js          # 或双击 启动服务器(浏览器用).bat
# 浏览器打开 http://localhost:9978
```

页面支持 **PWA 安装**:Chrome/Edge 地址栏出现「安装」图标,或菜单 → 安装应用;
安卓/电视浏览器可「添加到主屏幕」。安装后 UI 骨架离线可用(数据仍需网络)。

局域网内的电视/手机浏览器访问 `http://<电脑IP>:9978` 即可当电视应用用。

## 添加自己的采集源

1. 打开「设置」页 → 填入名称和苹果CMS接口地址,例如:
   `https://example.com/api.php/provide/vod/`
2. 添加后在顶栏「源: xx」或设置页点击「使用」切换。
3. 部分站点不开跨域头,保持**代理模式**开启即可(请求经本地服务器转发)。

> ⚠️ 免责声明:本项目仅提供播放器与源管理框架,不内置、不分发任何影视资源;请遵守当地法律,仅用于接入你有权访问的合法内容源。内置演示源为 Blender 开源短片,可离线体验完整流程。

## 实现说明(踩坑记录)

- **代理走 HTTP/2**:部分 CDN(如 Cloudflare)会按 TLS 指纹拦截 Node 的 HTTP/1.1 请求,
  HTTP/2 优先 + 失败回退 HTTP/1.1 可以显著提高兼容性。
- **不要伪装浏览器 UA**:上述站点还会校验 UA 与 TLS 指纹一致性,Node 指纹 + 浏览器 UA 会被 403;
  代理发送最少化的干净请求头反而畅通。
- **路径式代理前缀**(`/proxy/<url>`):m3u8 内的相对分段地址会自动解析回代理,整条 HLS 链路无遗漏;
  `/proxy2/` 为缓存隔离别名。
- **静态文件必须支持 Range**:否则浏览器把 `seekable` 置空,所有拖动进度条/seek 会被钳到 0。
- **MSE(hls.js)模式下不能调用 `video.load()`**,否则会重置掉已挂载的 MediaSource。
- **播放与进度**:暂停/每 5 秒/退出时三路保存进度;起播时若 currentTime 落在 MSE 缓冲区之外
  (PTS 偏移的流),自动跳到缓冲区起点,避免永久停滞。
