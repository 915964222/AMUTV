# 弹幕:开片自动获取(1.5)

目标:开片就有弹幕,不用手动点;匹配不到就留空,**不拿别的集/解说视频的弹幕凑数**。

## 一、三条来源与优先级

`POST /dm/fetch`(node `server.js` 与安卓壳 `MiniServer.java` 各一份,逻辑一致)

| 顺序 | 来源 | 触发条件 | 特点 |
|---|---|---|---|
| 1 | 自定义模板 `dmTpl` | 设置里填了含 `{fileName}` 的 URL | 你自己的聚合接口,返回 B站 XML 或 dandanplay JSON 都能识别 |
| 2 | 弹弹play 官方 | 填了 `dmAppId` + `dmAppSecret` | 按文件名匹配剧集,**国产剧/院线片最准** |
| 3 | B站内置 | 默认,免任何配置 | 按「片名 + 集数」搜,再用实际片长校正到具体某一集 |

前一条拿不到就顺延到下一条,不会因为弹弹play 401 直接把错误甩给用户。

## 二、B站免凭证是怎么做到的

2026-10 实测结论(都是踩出来的):

| 接口 | 裸调结果 | 解决 |
|---|---|---|
| `search/type` | **412 风控** | 必须带 `w_rid`(wbi 签名)+ `buvid3` 指纹 Cookie |
| `x/frontend/finger/spi` | 200 | 取 `data.b_3` 当 `buvid3` |
| `x/web-interface/nav` | 200,`code:-101`(未登录) | **未登录也返回 `wbi_img`**,img_url/sub_url 拼起来重排取前 32 位即 mixinKey |
| `x/web-interface/view` | 200 | 拿 `cid` 与 `pages[]` |
| `x/v1/dm/list.so?oid=<cid>` | 200,`Content-Encoding: deflate` | 浏览器 fetch 自动解压;Java 端要手动 `Inflater`(zlib 失败再试 raw) |

wbi 签名:`参数按 key 排序 → urlencode → 丢掉 !'()* → 末尾拼 mixinKey → md5`。
遇到 412 会自动换一次指纹重试(`biliSess.mixin=''` 强制重取)。

## 三、怎么判断「哪一集」

搜索结果的时长不可靠 —— 国产剧在 B站 多半只有**整部合集**(时长几小时)或**解说/混剪**,直接按时长挑必错。所以:

1. 用多个关键词各搜一遍(`片名 + 第N集` → `片名 第N集` → `片名`),凑 12 个候选;
2. 排序:标题里写明本集集数 > 时长接近 > 播放量;
3. 逐个看 `view` 的 `pages[]`:
   - **分P合集**(一集一个 P):先按 P 名里的集数认,再按片长 15% 内认;
   - **单集上传**:标题必须写明集数且与当前集一致,且不在黑名单(解说/解析/合集/预告/OST/有声书…),片长 15% 内;
4. 全都不满足 → 返回「没找到匹配的弹幕」,播放器**不显示任何弹幕**。

> 为什么这么严:错一集的弹幕在屏幕上刷,比没有弹幕更难受,而且会让人以为播放器坏了。

集数解析支持阿拉伯数字与中文数字:`第5集` = `第五集` = `第 05 集`,`第十二集` 也认。

## 四、播放器侧行为

- `确保开关`:设置 →「开片自动获取弹幕」默认开;播放器「弹幕」页里也有「自动 开/关」按钮。
- 时机:`video` 的 `playing` 事件触发一次;换集会重置,重新匹配。
- 缓存:同一次播放期间按 `片名|集名` 缓存在内存,来回切集不重复请求。
- 提示:成功 toast「弹幕 128 条 · B站｜庆余年---第四集 · 46分」;失败 toast「弹幕未加载 · 没找到匹配的弹幕」。
- 手动:「🌐 重新匹配弹幕」清缓存重试;面板底部显示当前来源与匹配到的视频。

## 五、已知限制

- **B站没有这一集就没有弹幕**:国产剧/院线片大量缺集,想要全覆盖只能走弹弹play(免费申请 AppId)。
- **番剧按季/按集上传的命中率高**(斗罗大陆这类),但合集类视频仍要依赖 P 名里的集数。
- 识别依赖网络;B站接口有 IP 风控,机房/代理 IP 可能长期 412。
- 弹幕按 `shift`(相对集首的秒数)对齐,若播放源剪掉了片头,弹幕会整体偏移(片头标记不参与校正)。
- 单次会话不做持久化缓存,重开播放器会重新请求一次。

## 六、排障

| 现象 | 先看 |
|---|---|
| 一直没弹幕、也没 toast | 设置里「开片自动获取弹幕」是否被关;`DB.getConfig().dmAuto` |
| toast「没找到匹配的弹幕」 | 正常结果(B站缺集),或片名与 B站 差异太大(如带「第二季」后缀) |
| toast「弹幕获取失败:…」 | 网络/风控;桌面端看 `server.js` 控制台,盒子看 `adb logcat -s TVDBG` |
| 弹幕对不上画面 | 看看面板底部「当前」里匹配到的视频是否同一集;必要时换弹弹play |
| 想验证接口 | `curl -X POST http://127.0.0.1:9978/dm/fetch -d '{"name":"庆余年","ep":"第04集","duration":2760}'` |
